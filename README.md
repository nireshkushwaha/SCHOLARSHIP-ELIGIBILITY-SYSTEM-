## Scholarship rules
- CGPA >= 7.00
- Attendance >= 75%
- Annual family income <= Rs. 5,00,000
- Backlogs <= 1
- Enrollment status must be Active

Highly Eligible additionally requires CGPA >= 8.50 and attendance >= 85%.
Conditionally Eligible is used when CGPA is from 6.75 to below 7.00 and all other mandatory checks pass.

All four sample student records are fictional demonstration data.
